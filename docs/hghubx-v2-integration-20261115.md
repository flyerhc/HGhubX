## 上游更新与审查

采用上游 2.0 的界面控件、主题、频道、搜索、图标、线路发现/自动换线、自定义线路、应用代理设置、代理变更恢复播放、Linux WebKit 代理策略、HTTP 响应 framing 修复和全部四个工作流。新增功能回归仍接入上游 CI；既有发布脚本注入防护、最小权限和临时签名密钥清理继续保留。

对本次增量的发布页解析、线路凭据信任、代理配置落盘、网络客户端、平台代理处理、热搜解析、图标/构建脚本和工作流进行了检查，未发现主观恶意执行或向无关服务窃取凭据的证据。发布页脚本作为数据解析，不执行其中的 JavaScript。此结论仅对应上述源码版本，不涵盖在线服务或已发布二进制。

两项实质安全策略差异已向用户说明并获得明确选择：

- **采用上游镜像登录策略**：固定站点、经发布页验证的镜像，以及用户明确保存的当前自定义线路可以获得登录凭据；旧格式线路配置不自动授予自定义登录许可。会话继续绑定 origin，账号请求不跟随会重放凭据的重定向。原审查中的“镜像仅游客、凭据信任只限两个固定站点”已被这项明确选择替代。
- **保留代理下的严格 DNS/IP 检查**：不采用上游“判定代理启用后跳过本地解析/IP 检查”的分支。仍验证 DNS 答案、保留 IPv4/IPv6 CIDR 例外和默认 FakeIP 范围。可信代理最终使用的远端解析地址无法仅靠本地检查证明；纯远端解析的代理环境也可能需要调整本地 DNS/FakeIP 设置。

## 新增功能适配

- 保留默认 256 MiB、0/128–4096 MiB 的磁盘缓存、关闭清理、前台优先、两个后台槽、部分块补齐、HLS 音轨/字幕/密钥与 MP4 Range 缓存。上游 Linux 响应长度修复与本地 Host/Origin、头大小和并发限制同时保留。
- 独立观看进度、旧 writer 拒绝、片尾回拖、画质切换保位和自动续集接入新版 Feed；保留上游 desktop playback clock，避免每次 timeupdate 重绘整页。
- 采用上游 `hghubx_*` 存储键及旧键迁移，保留独立 progress 映射和字幕偏好。本地测试同步使用新键，上游旧键迁移用例继续保留。
- 两个播放器同时保留缓存/字幕与上游代理恢复；新增代理恢复后的持久化进度断言，防止重载把进度写成零。
- 新增缓存/CIDR 控件使用上游控件封装。测试适配新版 switch 语义，并在测试手动暂停前唤醒自动隐藏的控制条；两个上游测试使用 Playwright 默认浏览器，继续支持环境变量指定浏览器。
- Unix 会话目录 0700、文件 0600 和导航限制继续保留。移动端仍是 HGhubX 的 Tauri 架构，不声称恢复了已移除的独立原生客户端 Keychain/Keystore、原生 PiP 或 Swift SIGPIPE 实现，具体边界见完整清单。
