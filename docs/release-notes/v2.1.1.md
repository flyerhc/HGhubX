## HGhubX 2.1.1

本次为 2.1 的修复更新，主要改善评论区显示。

### 更新点

- 手机播放页面以评论数量替代“评论”文字，保留评论图标。
- 更新了 README。

### 修复点

- 修复部分评论中的 HTML 标签和脚本片段原样显示、占据大量空间的问题，保留正常文字、表情和换行。
- 修复长评论和长昵称的换行布局。
- 评论面板优先显示当前剧集的评论数量，切集后重新获取；补齐吃瓜帖评论数量的读取。

### 构建产物

- Linux amd64：`.deb`
- Android：arm64、arm、x86_64 分 ABI APK
- Windows：x64 安装包和便携版 ZIP
- macOS：Universal `.dmg`
- iOS：未签名 `.ipa`
